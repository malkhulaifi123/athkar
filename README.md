# وِرد — أذكار الصباح والمساء والنوم

موقع عربي خفيف ومتجاوب يضم ثلاثة أقسام: **أذكار الصباح** و**أذكار المساء** و**أذكار النوم**.

## المميزات
- صفحة رئيسية بها ثلاث بطاقات للانتقال إلى الأوراد.
- عدّاد مستقل أسفل كل ذكر، يتوقف عند العدد المحدد، مع زر للتراجع.
- متابعة عدد الأذكار المكتملة، وشريط تقدم، وتصفية المكتملة والمتبقية.
- حفظ العدادات محليًا في المتصفح لكل قسم، وإعادة البدء تلقائيًا عند تغيّر التاريخ المحلي.
- إمكانية إعادة ضبط الورد يدويًا بعد تأكيد العملية.
- مظهر فاتح وداكن وتصميم عربي متجاوب مع الهاتف.
- روابط إلى مصادر النصوص وملاحظات حين يوجد اختلاف في ثبوت تخصيص ذكر أو عدده.
- لا يحتاج إلى تسجيل دخول أو قاعدة بيانات.

## فتح الموقع محليًا
افتح ملف `index.html` في متصفح حديث. الملفات مستقلة ولا تتطلب تثبيت حزم. تُستخدم خطوط Google Fonts اختياريًا، مع خطوط احتياطية عند انقطاع الإنترنت.

## نشر الموقع على GitHub Pages
1. في المستودع، افتح **Settings → Pages**.
2. إذا كان نوع الحساب لا يسمح بنشر Pages من مستودع خاص، غيّر ظهور المستودع إلى **Public** من إعداداته بعد التأكد أنك تريد أن يكون الكود عامًا.
3. ضمن **Build and deployment**، اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/(root)`، ثم احفظ.
5. بعد اكتمال النشر، سيكون العنوان عادةً `https://malkhulaifi123.github.io/athkar/`.

> رفع الملفات إلى GitHub لا يعني أن النشر على GitHub Pages قد فُعّل. يجب تمكين Pages في إعدادات المستودع. الرابط أعلاه هو العنوان المتوقع بعد النشر وليس رابطًا تم التحقق من تفعيله.

## عن المصادر
المحتوى انتقاء من أذكار الكتاب والسنة ويستند إلى كتاب **حصن المسلم**، مع روابط إلى القرآن والأحاديث. لا يُقصد بالقائمة حصر جميع الأذكار، وقد تختلف أحكام العلماء على بعض الروايات، وقد عُلّق على بعض مواضع الخلاف. ينبغي الرجوع إلى النصوص والمراجع الأصلية عند التحقق.

- [حصن المسلم](https://sunnah.com/hisn)
- [أذكار الصباح والمساء](https://islamqa.info/ar/answers/217496)
- [أذكار النوم الصحيحة](https://islamqa.info/ar/answers/145543)

## ملاحظة خصوصية
لا يجمع الموقع أي بيانات شخصية. يتم حفظ حالة العدادات والمظهر في `localStorage` على الجهاز ذاته. مسح بيانات المتصفح أو استخدام جهاز آخر يؤدي إلى فقدان التقدم.
